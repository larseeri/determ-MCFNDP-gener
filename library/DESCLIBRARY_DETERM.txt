Description of the library of generated deterministic MCFNDP instances


A generic library of deterministic MCFNDP instances is created with the GenDeterm generator based on the following arborescence of configurations. First, subsets of instances are generated under one of two primary topologies: either point-to-point (Section 1) or hub-and-satellite (Section 2). Second, within each one these subsets, two further subsets of instances are respectively generated under one of two regimes of distribution of commodity volumes: either one source node and one sink node for each commodity (Sections 1.1 and 2.1), or multiple but identical source nodes and multiple but identical sink nodes for all commodities (Sections 1.2 and 2.2). Third, within each one of these subsets, four subsets of instances are respectively generated under one of four secondary topologies: circular (Sections 1.1.1, 1.2.1, 2.1.1, 2.2.1), cylindrical (Sections 1.1.2, 1.2.2, 2.1.2, 2.2.2), flat (Sections 1.1.2, 1.2.2, 2.1.2, 2.2.2), toral (Sections 1.1.2, 1.2.2, 2.1.2, 2.2.2). We proceed to describe the exact sets of options and option values appearing in the configurations situated at the leaves of this arborescence.

Remarks:

a- The objective underlying the construction of the library with the GenDeterm generator is to produce a set of deterministic MCFNDP instances featuring broadly diversified topologies, characteristics and complexity levels from which the user could select and/or sample a most relevant subset to run experiments at hand. Yet, the library could be expanded through further diversifications along settings of the generator that are presently fixed or by exploring alternative ranges or sets of values about some other settings.

b- The library defines a total of 6000 MCFNDP configurations and is stored in the /library folder.

c- Feasibility of each MCFNDP instance generated from the configurations in the library has been verified with the program contained in the /check_feasib folder. The 9 infeasible instances are removed from the regular subfolders and stored in infeas/ subfolders as indicated below.

d- In view of the large space that would be required to store all MCFNDP instances, only the configuration files are supplied within two .zip archives: hubsAndSats_config-files.zip and pointToPoint._config-files.zip. The corresponding MCFNDP instances can be generated from the saved configuration files at a high speed using the program contained in the /program folder.

e- The C++ code building configuration files for each instance in the library is located in folder library/build_config.


1 Primary topology: Point-to-point (3600 configurations)

Configurations within this branch feature a point-to-point primary topology. That is, option "hubSat" is omitted or its value is set to false. The following option values are common to all configurations in this branch:

Option and value specifying the number of successive attempts to generate a random arc while avoiding parallelism:
noParalArc 20

Options and values specifying the range of the sampling distribution for the commodity volumes:
minComVol 20
maxComVol 100

Options and values specifying the ranges of the sampling distribution for the fixed costs and variable costs over the arcs:
minFixCos 20
maxFixCos 100
minVarCos 20
maxVarCos 100

Notice that the resulting sampling distributions are deliberately made to be wide, ratios between maxima and minima being equal to 5. Control of the balance between volumes and capacities and between fixed costs and variable costs is deferred to values of options "adjCapacsDown" and "adjFixCostsUp", as described below.

Remark:

All configuration files belonging to the current branch are saved in folder library/pointToPoint
